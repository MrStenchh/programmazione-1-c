# Programmazione 1 - C

Progetto universitario sviluppato in linguaggio C per il corso di Programmazione 1.

## Progetti

### Gioco della macchina
Piccolo gioco sviluppato in C in cui una macchina deve muoversi lungo un percorso evitando gli ostacoli.

### Dizionario dei contrari
Programma sviluppato in C per la gestione di un dizionario di parole e dei relativi contrari.

## Tecnologie

- C
- Strutture dati

## Contesto

Progetto realizzato nell'ambito del corso di Programmazione 1 presso l'Università degli Studi di Napoli "Parthenope".
